# Referencia histórica — inventario anterior (v1)

Estos cinco archivos fueron proporcionados como antecedente del proyecto AuditaPC:

- `Iniciar-Inventario.bat`
- `Inventario-Equipo.ps1`
- `LEEME.txt`
- `Unificar-Inventarios.bat`
- `Unificar-Inventarios.ps1`

Se conservaron **sin alterar su contenido**. Úsalos únicamente para comprender el enfoque original de captura y consolidación. El agente puede diseñar AuditaPC desde cero; estos scripts no determinan el lenguaje, la interfaz ni la arquitectura futura.

**No ejecutarlos como parte automática del nuevo proyecto.**
